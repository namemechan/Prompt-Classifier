# Prompt Classifier

이미지 파일에 내장된 프롬프트 정보를 읽어, 사용자가 정의한 규칙에 따라 이미지를 분류하고 정리하는 도구입니다.

## 🖥️ 사용 방법

### 🚀 실행

1.  패키징된 `Prompt-Classifier.exe` 파일을 실행합니다.
    *   **참고**: 설정 및 프리셋은 `Prompt-Classifier.exe`와 같은 폴더 내 `ImageClassifier` 폴더에 저장됩니다. 만약 `exe` 파일이 쓰기 권한이 없는 위치(예: `C:\Program Files`)에 있다면, 설정 저장이 실패할 수 있으니, 쓰기 가능한 다른 위치로 옮겨서 사용해주세요.

### 💡 UI 가이드

애플리케이션 실행 후 나타나는 창에서 다음 단계를 따르세요.

1.  **소스 디렉토리 설정**:
    *   `소스 디렉토리` 옆의 `찾아보기...` 버튼을 클릭하여 이미지가 저장된 폴더를 선택합니다.

2.  **분류 옵션 설정**:
    *   **`이름 변경`**: 이 옵션을 선택하면, 분류된 이미지 파일명이 해당 프롬프트 키워드를 포함하도록 자동으로 변경됩니다. (예: `landscape_000001.png`)
    *   **`그 외 처리`**: 이 옵션을 켜면, 분류되지 않은 나머지 파일들이 `other`라는 하위 폴더로 자동으로 이동됩니다.
    *   **`동일명 숫자 추가`**: 이 옵션을 켜면, 이동할 폴더에 이미 같은 이름의 파일이 존재할 경우 파일명 뒤에 `(01)`, `(02)` 같은 숫자를 붙여 이름 충돌을 방지합니다. 이 옵션을 끄면 동일명 파일은 이동되지 않고 건너뛰며, 건너뜀 사실이 로그에 표시됩니다.
    *   **`안전 모드`**: 파일을 즉시 이동하는 대신, 먼저 대상 위치로 **복사**합니다. 복사 완료 후 팝업창을 띄워 원본 파일을 **[삭제]**, **[보존]**, 또는 작업을 **[실행 취소]**(복사본 삭제)할지 선택하도록 합니다. 데이터 유실을 방지하는 가장 안전한 방법입니다.
    *   **`복제 모드`**: 파일을 이동하는 대신 대상 위치로 **복사**합니다. 원본 파일은 그대로 유지됩니다.
    *   **참고**: `안전 모드`와 `복제 모드`는 동시에 사용할 수 없습니다.
    *   **`전체추적`**:
        *   이 옵션을 켜면, `소스 디렉토리`와 그 하위의 **모든 폴더**를 재귀적으로 검색하여 이미지를 분류합니다.
        *   `포함 키워드` 입력란에 찾을 프롬프트 키워드를, `제외` 입력란에 결과에서 제외할 키워드를 `|` (파이프) 문자로 구분하여 입력하세요. (예: 포함: `fantasy | cyberpunk`, 제외: `nsfw | sketch`)
        *   **참고**: `전체추적`이 활성화되면 `레벨 1~5`의 분류 옵션은 자동으로 비활성화됩니다.
    *   **`사용자 폴더 사용`**:
        *   이 옵션을 켜면, 분류된 이미지가 키워드 이름의 하위 폴더 대신 사용자가 직접 지정한 **단일 대상 폴더**로 이동합니다.
        *   `찾아보기...` 버튼을 눌러 원하는 폴더를 선택하세요. 모든 분류 결과를 한 곳에 모으고 싶을 때 유용합니다.
    *   **`레벨 1~5`**:
        *   `전체추적`이 **꺼져 있을 때**만 사용됩니다.
        *   각 레벨의 체크박스를 켜서 해당 레벨의 분류를 활성화합니다.
        *   각 레벨에는 **포함 키워드**와 **제외 키워드** 입력란이 각각 있습니다. 포함 키워드에 매칭되더라도 제외 키워드가 프롬프트에 포함되어 있으면 해당 이미지는 건너뜁니다.
        *   키워드는 `|` (파이프) 문자로 구분합니다. (예: 포함: `landscape | nature`, 제외: `lowquality`)
        *   이미지는 레벨 순서대로 분류되며, 이전 레벨에서 분류된 이미지는 다음 레벨 처리 대상에서 제외됩니다.

3.  **분류 시작**:
    *   모든 설정을 마친 후, `분류 시작` 버튼을 클릭합니다.
    *   진행 상황은 진행 표시줄과 로그 영역에서 실시간으로 확인할 수 있습니다. 완료 시 로그에 총 소요 시간과 처리된 이미지 수가 표시됩니다.

4.  **작업 관리**:
    *   `취소` 버튼을 클릭하여 진행 중인 작업을 중단할 수 있습니다.
    *   `이전 작업 취소` 버튼을 클릭하여 가장 최근에 완료된 작업을 되돌릴 수 있습니다.

5.  **프리셋 활용**:
    *   현재 설정을 프리셋으로 저장하여 나중에 다시 불러올 수 있습니다. `저장` 버튼을 클릭하고 프리셋 이름을 입력하세요.
    *   저장된 프리셋은 드롭다운 메뉴에서 선택하여 불러올 수 있습니다.
    *   불필요한 프리셋은 `삭제` 버튼으로 제거할 수 있습니다.

## 변경 내역

### v3.0.0
*   신규 기능: 제외 키워드 지원 — 레벨 1~5 및 전체추적 모드 모두에서, 지정한 키워드가 프롬프트에 포함된 이미지를 분류 결과에서 제외할 수 있습니다.
*   버그 수정: 다중 레벨 + `그 외 처리` 조합 사용 시, 이미 분류된 파일이 `other` 폴더로 중복 이동되던 문제 수정.
*   버그 수정: `동일명 숫자 추가` 옵션이 꺼진 상태에서 동일명 파일을 건너뛸 때 로그에 표시되지 않던 문제 수정.
*   버그 수정: 프리셋 불러오기 시 `안전 모드` / `복제 모드` 체크박스 활성화 상태가 꼬이던 문제 수정.
*   버그 수정: exe 패키징 환경에서 설정 및 프리셋 저장 폴더(`ImageClassifier`)가 생성되지 않던 문제 수정.

### v2.0.0
*   개선 사항: ComfyUI 로직 개선, 코드 개편.
